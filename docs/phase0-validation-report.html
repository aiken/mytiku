问题分析

1. 图片提取率统计口径问题

现象：图片提取率 44.1%，未达 90% 目标。
根因：选择题（16.5%）和填空题（45.4%）本身为纯文字题型，不含图片。按"有图题目"口径统计，提取成功率为 100%。
建议：验收标准应区分"有图题目提取率"和"全部题目图片率"。

2. 解题方法 (method) 维度覆盖率偏低

现象：method 维度覆盖率 46.6%，低于 knowledge (70.5%) 和 ability (78.0%)。
根因：method 标签依赖 knowledge 标签反向推断（如"几何"→"数形结合"），部分题目 knowledge 标签缺失导致 method 无法推断。
建议：增强 method 规则的正则匹配，直接从题目内容识别解题方法关键词。

3. 考试说明页被误识别为题目

现象：约 17.9% 题目被标记为"需人工复核"，内容多为"本试卷共 X 页"、"考试时间 120 分钟"等考试说明。
根因：题号正则匹配到了说明页的分页标记（如 "1．" 开头）。
建议：增加内容过滤规则，排除长度 < 50 字或包含"本试卷"、"考试时间"等关键词的伪题目。

4. 元数据"未知"值

现象：约 10-15% 试卷的 district/school/round 标记为"未知"。
根因：文件名中未包含明确的区名/学校名，或使用了非标准命名（如"北京二十一中"未在别名映射表中）。
建议：扩充 metadata_mappings.py 中的学校别名表，增加更多学校简称映射。
